# 각성 시뮬레이터

게임의 **각성 시스템**을 브라우저에서 직접 체험할 수 있는 웹 시뮬레이터입니다.
실제 재화 소모 없이 각성 결과를 미리 시뮬레이션해 보세요.

**[시뮬레이터 바로가기](https://architect-tools.github.io/architect-awaken-simulator/)**

---

## 주요 기능

### 셀 개방 & 각성
- 15개 페이지의 헥사곤 그리드를 게임과 동일하게 재현
- 셀 개방 (3단계) → 각성 (1~6성) 흐름을 그대로 시뮬레이션
- 각성 시 선택 셀 + 인접 셀이 동시에 등급 변경

### 자동 각성
- **자동 개방**: 페이지 내 모든 셀을 원클릭으로 3단계 개방
- **자동 각성**: 목표 종합 등급에 도달할 때까지 연속 각성
  - 5성·6성 도달 시 중지 조건 설정 가능
  - 실행 속도 조절 지원

### 최적 경로 탐색
- 알고리즘 기반으로 각성 최적 경로를 자동 계산
- 가이드 오버레이로 경로를 단계별로 시각화
- 즉시 실행 또는 애니메이션 실행 선택 가능

### 편의 기능
- **등급 직접 입력**: 원하는 셀의 등급을 수동 지정
- **설정 패널**: 캐릭터 레벨, 아니마, 골드 자유 조정
- **자동 저장**: 브라우저에 진행 상태 자동 저장 (localStorage)
- **밸런스 리포트**: 페이지별 재화 소모 통계 확인

## 각성 확률

게임과 동일한 확률표를 적용합니다.

| 등급 | 색상 | 확률 |
|------|------|------|
| 1성 | ⬜ 회색 | 41% |
| 2성 | 🟩 녹색 | 20% |
| 3성 | 🟦 파란색 | 17% |
| 4성 | 🟥 빨간색 | 10% |
| 5성 | 🟪 보라색 | 9% |
| 6성 | 🟨 노란색 | 3% |

## 사용 방법

1. [시뮬레이터](https://architect-tools.github.io/architect-awaken-simulator/)에 접속합니다.
2. 상단에서 원하는 **페이지 번호**를 선택합니다.
3. 셀을 클릭하여 **개방** (3단계까지 반복) 합니다.
4. 모든 셀이 3단계 개방되면 **각성**이 활성화됩니다.
5. 셀을 클릭하면 해당 셀 + 인접 셀의 등급이 무작위로 변경됩니다.
6. **자동 각성** 또는 **최적 경로** 기능으로 목표 등급까지 한 번에 진행할 수도 있습니다.

> 시뮬레이터에서는 재화의 제한이 없습니다.
